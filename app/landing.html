Frequently Asked Questions.

Clear answers about migration, privacy, DRM, and open-source licensing.

Can I migrate my existing library from Calibre or folder collections?
Yes. Simply drag and drop your existing ebook collection folder directly into FolioHaven. Because FolioHaven uses non-destructive indexing and cryptographic hash deduplication, it catalogs your books without duplicating files or rearranging your folder structure on disk. You can safely point FolioHaven directly at your existing Calibre library folder.
How does FolioHaven handle DRM-protected books?
FolioHaven is built for open, private reading and supports DRM-free EPUB, PDF, MOBI, FB2, CBZ, and TXT files. It does not contain decryption keys for proprietary Adobe Adept or Amazon Kindle DRM systems. If an encrypted file is opened, FolioHaven displays a calm, helpful explanation rather than crashing or freezing.
Does FolioHaven require an account or an internet connection?
Never. FolioHaven is strictly local-first. There is no account sign-up, no email registration, no cloud login, and zero network telemetry. All library records, bookmarks, highlights, and reading statistics remain stored on your local machine in an open SQLite database.
Is FolioHaven truly free, or will subscription paywalls be added later?
FolioHaven is released under an open-source license. The desktop application is free and will always remain free. We will never add paywalls, library size limits, or nag popups. The project is sustained purely through voluntary patron contributions and GitHub sponsorships from readers who appreciate quiet software.
What operating systems and platforms are supported?
FolioHaven runs as a native 64-bit application on Windows 10 and Windows 11. It is also available as a modern web application accessible from any standard desktop browser (Chrome, Edge, Firefox, Safari) with local IndexedDB storage.
