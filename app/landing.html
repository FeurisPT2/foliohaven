Frequently Asked Questions.

Clear answers about migration, privacy, DRM, and open-source licensing.

Have technical questions? Inspect our open-source codebase on GitHub.
Can I migrate my existing library from Calibre or folder collections? +
Yes. Simply drag and drop your existing ebook collection folder directly into FolioHaven. Because FolioHaven uses non-destructive indexing and cryptographic hash deduplication, it catalogs your books without duplicating files or rearranging your folder structure on disk.
How does FolioHaven handle password-protected documents? +
FolioHaven includes native document decryption for password-protected PDF and encrypted ebook files. When opening an encrypted file, a secure password modal prompts for the decryption key and validates access directly.
Does FolioHaven require an account or an internet connection? +
Never. FolioHaven is strictly local-first. There is no account sign-up, no email registration, no cloud login, and zero network telemetry. All library records, bookmarks, highlights, and reading statistics remain stored on your local machine in an open database.
Is FolioHaven truly free, or will subscription paywalls be added later? +
FolioHaven is released under an open-source license. The desktop application is free and will always remain free. We will never add paywalls, library size limits, or nag popups. The project is sustained purely through voluntary patron contributions.
