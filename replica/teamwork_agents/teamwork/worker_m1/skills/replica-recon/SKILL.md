Key steps:
1. Scope: Which app, which platform, which slice, who it is for.
2. Sources table: Public sources & clean-room inspection.
3. Screen inventory: Stable IDs S01, S02... Route, purpose, key components, states (empty, loading, populated, error).
4. User flows: F01, F02... Happy path clicks, edge cases.
5. Components: Reusable parts, variants, states, usage.
6. Inferred data model: Entities, fields, relationships, evidence, confidence.
7. Feature matrix: features.csv (feature,area,priority,original,clone,complexity,notes).
8. Non-cloneable: DRM, proprietary cloud, etc.
9. Sizing: S/M/L/XL.
